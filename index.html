03 / Selected engagements

Work that shipped.

  1. Conversational analytics that lets operations teams ask about order fulfilment, inventory and logistics in natural language. Architected and led end to end.

    • Production LangGraph multi-agent pipeline — skill selection, intent classification, a tool-calling planner/executor, synthesis, deterministic critique and an executive summary — over a plug-in “agent skills” framework.
    • Python/FastAPI backend with Server-Sent Events streaming on Azure Kubernetes Service, integrating RisingWave (streaming SQL over Kafka), Redis and Azure Cosmos DB.
    • Purpose-built, pre-validated metric tools instead of free-form LLM-generated SQL — eliminating SQL-injection risk and improving reliability and auditability.
    • Okta OAuth2, Azure Key Vault secrets, structured logging and tracing, and strict PII guardrails.
